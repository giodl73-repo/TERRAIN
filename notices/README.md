# Original notices

`../LICENSE` retains TERRAIN's existing first-party grant. It does not replace
the individual grants on locked dependency sources or Rust runtime code.

`../DEPENDENCY-NOTICES.txt` concatenates every original license/copyright/notice
file found in all 27 locked registry/Git source archives. Original bytes follow
clearly labeled package/path separators without text normalization. The input
verifier checks the complete original file/grant inventory; the site builder
requires this concatenation to agree exactly before publishing it.

`rust-1.95.0-COPYRIGHT-library.html` is the complete, unmodified runtime library
notice supplied by the installed Rust 1.95.0 rust-docs distribution. Its size,
hash and scope are in `RUNTIME-NOTICES.json`. It has no automatic stylesheet,
script, font or image resource dependency. Compiler/linker/bindgen/browser tools
remain installed prerequisites and are not redistributed with the small site.

These records preserve upstream terms and attribution. Integrity checks do not
establish authorship, grant additional rights or certify operational results.
