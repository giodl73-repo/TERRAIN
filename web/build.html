Receive without Git

Prerequisite: Python 3.11+ with its standard library including lzma. Inspect and trust the receiver bundle first, then unpack its three Python modules into a new helper directory. It uses no pip packages, Git, Cargo or network during receipt. From that directory:

python -I -S -B receive-source.py --archive /downloads/source.tar.xz --sha256 @@SOURCE_SHA@@ --output /new/TERRAIN --protect /your/compiled-target

Choose a new source directory outside the helper, download and compiled-target directories. Verification bounds archive resources, checks the full Git tree/commit/file/mode inventory, rejects links and unsafe paths, and preserves existing destinations. POSIX disk executable modes are checked on POSIX; Windows preserves the archived mode inventory without claiming equivalent ACLs.

Build offline from original inputs

Install Rust 1.95.0 (including wasm32-unknown-unknown), wasm-bindgen CLI 0.2.127 and Python 3.11+ separately. These tools are external prerequisites, not included installers. The archive includes all committed application files, complete original locked dependency archives and their grants. Building executes the received Rust source: review it before building.

From the restored TERRAIN directory, with three new directories outside the source for original inputs, Cargo home and compiled target:

python tools/build-pages.py --inputs /new/terrain-inputs --cargo-home /new/terrain-cargo-home --target /new/terrain-target

The builder restores and reads back the offline input kit, requires the locked sources, remaps source/dependency/target diagnostic paths, and writes a new dist/TERRAIN. It checks the complete published package is below 5,000,000 bytes. Serve it with python -m http.server 8767 --directory dist and open http://localhost:8767/TERRAIN/. Opening the HTML directly as a file is not supported.

For validation, Node 22 and the locked npm development dependencies plus Playwright Chromium are additional external prerequisites. Run the documented tools/check-planner.py comparison and npm test. A new empty target tests compilation independently of an existing compiled cache. Same-platform, same-toolchain byte comparison is a separate qualification; cross-platform compiler identity is not promised.
