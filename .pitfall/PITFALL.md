# TERRAIN PITFALL index

TERRAIN uses PITFALL as a compact index over customer territory-planning
doctrine: auditable tradeoffs, dashboard-bound exports, people-capacity
fairness, field review, and shared-kernel boundaries. The index cites existing
roles, product docs, wave closeouts, schemas, fixtures, and validation commands
without moving local sources of truth.

## Integration

- ROLES: `.roles/ROLE.md` routes territory, buyer, visual, data-binding,
  fairness/capacity, and kernel-boundary changes to matching reviewers.
- VTRACE: TERRAIN does not yet carry repo-local VTRACE docs; PITFALL cites
  waves, role reviews, product docs, dashboard schemas, fixtures, and
  validation commands until a trace layer exists.
- Tests: workspace tests, CLI sample commands, schema output, packet commands,
  strict formatting, and PITFALL validators are the executable evidence hooks.
